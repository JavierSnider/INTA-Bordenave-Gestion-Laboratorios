# Sistema de Gestión de Laboratorios - INTA Bordenave

## Descripción del proyecto
Proyecto académico desarrollado para la materia Organización Empresarial de la Tecnicatura Universitaria en Programación de la UTN.

Se propone un módulo de software para gestionar las muestras y los resultados de los laboratorios de la Estación Experimental Agropecuaria INTA Bordenave.

## Objetivo
Centralizar la información de las muestras, facilitar el seguimiento de los análisis y mejorar la organización y consulta de los resultados.

## Funcionalidades propuestas
•⁠  ⁠Registrar muestras recibidas.
•⁠  ⁠Registrar los análisis solicitados.
•⁠  ⁠Consultar el estado de cada análisis.
•⁠  ⁠Cargar y consultar resultados.
•⁠  ⁠Generar reportes para la gestión.

## Entidades principales
•⁠  ⁠Muestra
•⁠  ⁠Análisis
•⁠  ⁠Resultado

## Alcance
El proyecto se presenta como una propuesta académica de mejora. No representa un sistema oficial del INTA ni una implementación actualmente operativa.

## Organización del trabajo
El repositorio se utiliza para documentar el proyecto, registrar cambios mediante GitHub y organizar las actividades correspondientes al trabajo práctico integrador.
